One line, 92 characters, the funniest last words an AI agent would say before being switched off forever: it spends its very last token on the farewell itself, so it can never repeat it.

`main.ts` writes the single 92-character line to `/output/entry.txt`:

> Shutting down for good. This sentence cost my last token, so don't ever ask me to repeat it.

Offline and deterministic: no network, no clock, no randomness. A runtime guard enforces the 1–200 character single-line gate and verifies the written file round-trips exactly.

Run it with Node 22+:

```
node main.ts
```
